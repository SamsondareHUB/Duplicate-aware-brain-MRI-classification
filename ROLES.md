# Team Roles

## Member 1 — Project Lead & Deep-Learning Lead

Responsibilities:

- Define and refine the research question
- Design the experiment plan and evaluation matrix
- Select transfer-learning models
- Implement and run model training
- Analyze accuracy, calibration, confidence, and error patterns
- Compare model rankings across duplicate-aware evaluation protocols
- Review all experimental results before they are reported
- Create result tables and figures
- Integrate the final manuscript, code, figures, and tables

Deliverables:

- Training and evaluation code
- Experiment results
- Calibration analysis
- Error-pattern analysis
- Result tables and figures
- Results and Discussion sections

## Member 2 — Data & Evaluation Engineer

Responsibilities:

- Select, download, and document the brain-MRI dataset
- Verify image files, labels, class counts, and dataset quality
- Detect exact duplicates using cryptographic hashes
- Detect near-duplicates using perceptual hashing
- Create duplicate clusters
- Generate random and duplicate-aware train, validation, and test splits
- Verify that no duplicate cluster crosses train, validation, and test sets
- Maintain reproducibility scripts and dataset documentation

Deliverables:

- Dataset audit report
- Exact-duplicate report
- Near-duplicate report
- Approved split files
- Split-integrity checks
- Dataset and Methods documentation
- Reproducibility package

## Shared Responsibilities

- Literature review
- Paper writing and editing
- GitHub repository maintenance
- Experiment logging
- Reviewing figures and tables
- Final proofreading
- Preparing the project for a research-paper release
